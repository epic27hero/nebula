================================================================================
                    COMPLETE RESPONSIBILITY CHAIN
================================================================================

CI (GitLab) ──DECIDES──▶ Image tag (via commit SHA)
                      ▶ Build time (UTC timestamp)
                      ▶ App version (tag or SHA)
                      
Docker Image ──CARRIES──▶ Baked metadata (ENV from ARGs)
                       ▶ Runtime introspection
                       
Helm ──RENDERS──▶ YAML templates
               ▶ No logic, just values
               
Kubernetes ──CONTROLS──▶ Pod scheduling
                      ▶ Traffic routing (readiness probes)
                      ▶ Rolling updates (zero-downtime)
                      
ArgoCD ──ENFORCES──▶ Git = Cluster state
                   ▶ Drift correction
                   
App ──PROVES──▶ Reality (version metadata)
             ▶ Health/readiness status
             
Metrics ──MEASURES──▶ Request rates
                    ▶ Error rates
                    ▶ Pod uptime
